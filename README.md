# GitHub Profile Viewer

GitHub Profile Viewer is a web application that allows users to search for and view GitHub profiles. It fetches data from the GitHub API and displays user information such as repositories, followers, and more.

## Features
- Search for GitHub profiles by username.
- View user details including bio, repositories, and followers.
- Responsive and user-friendly interface.

## Getting Started

### Prerequisites
- Ensure you have [Node.js](https://nodejs.org/) installed on your system.
- A GitHub personal access token 

### Clone the Repository
To clone this project, run the following command in your terminal:
```bash
git https://github.com/Yorsyboy/github-profile-viewer.git
```

### Install Dependencies
Navigate to the project directory and install the required dependencies:
```bash
cd github-profile-viewer
npm install
```

### Run the Application
Start the development server:
```bash
npm start
```
The application will be available at `http://localhost:5173/`.

## Usage
1. Open the application in your browser.
2. Enter a GitHub username in the search bar.
3. View the profile details and explore repositories.
